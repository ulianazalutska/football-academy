## Секція 01 (шапка)

- Шапка фіксована: ховається при скролі вниз, повертається при скролі вгору.
- Меню: Manrope 24px, regular, letter-spacing 4%. Якорі: Програми `#programs`, Тренерки `#coaches`, Батькам `#safety`, Кемпи `#camps`; «ЗВ'ЯЗАТИСЯ» `#contact-form`; логотип `#top`.
- Hover пунктів меню: колір тексту рожевий (`--color-accent`).
- Активний пункт підсвічується при скролі до секції (зелений `--color-primary`, моє припущення). Бургер-меню поки не робимо (на ≤767px пункти меню ховаються).

## Технічні підходи до адаптивності

- Заголовки масштабуємо плавно через `clamp()`, а не стрибками по медіазапитах.
- Адаптивні картки робимо на CSS Grid з `auto-fit` і `minmax()`, щоб зменшити кількість медіазапитів.
- Контейнер: `.container` у `src/styles/base.css`, `--gutter` 40px (32px на ≤767px).
