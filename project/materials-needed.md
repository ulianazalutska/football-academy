# Що потрібно від вас: загальний список

Окремі списки по секціях лежать у папках `project/sections/<секція>/needed.md`. Тут тільки те, що стосується всього сайту. Закреслюйте (`[x]`) те, що вже передали.

## Для кожної секції (передається, коли ми до неї дійдемо)
- [ ] Значення з Figma: розміри шрифтів, вага, міжрядковий інтервал, відступи, ширини колонок, радіуси. Усі «≈» у `tokens.css` і секціях виміряні зі скриншота.
- [ ] Фото й іконки секції (WebP / SVG, див. `needed.md` у папці секції).
- [ ] Рішення з анімацій (ви пояснюєте самі під час секції).
- [ ] Відповіді на [ПИТАННЯ] секції.

## Контент, якого немає в дизайні
- [ ] Відповіді на 7 питань FAQ.
- [ ] Слайди тренерок 2–5: ім'я, посада, цитата, фото.
- [ ] Деталі двох кемпів: вік, ціна, кількість місць.
- [ ] Повний список логотипів клубів і університетів.
- [ ] Відео: файл або посилання (секція 07 і відео в hero).
- [ ] Посилання на Instagram, TikTok, YouTube.
- [ ] Юридичні документи: Політика конфіденційності, Політика захисту дітей, Умови використання (тексти або PDF).
- [ ] Англійські тексти для перемикача (наприкінці проєкту).

## Рішення, які ще відкриті
Див. `project/decisions.md` (питання 13–41 відкладені до секцій) і розділи [ПИТАННЯ] у `project/sections/*.md`.
